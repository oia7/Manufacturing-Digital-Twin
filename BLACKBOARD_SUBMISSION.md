# Blackboard submission — Project 2

**Project:** FORGE — Manufacturing Digital Twin

**Description:** An interactive software-based digital twin prototype of a four-stage industrial valve production line. The application virtually monitors production, analyzes equipment effectiveness and quality, predicts maintenance risks using a transparent rule-based model, and supports lifecycle decisions through a configurable Rev A/Rev B redesign comparison. Users can inject faults, schedule maintenance, vary production pace, and export simulated telemetry.

**Live application URL (after GitHub Pages is enabled):** https://oia7.github.io/Manufacturing-Digital-Twin/

**Repository URL:** https://github.com/oia7/Manufacturing-Digital-Twin

**Technology:** HTML, CSS, JavaScript (ES modules), Node.js built-in test runner; no backend.

**Validation:** 21 automated consistency/unit tests passed. Interactions were also checked in a Chromium browser. There is no connection to a real manufacturing plant; equipment/sensor data and financial inputs are illustrative.

**How to demonstrate:** Open the live UI, allow the factory to run, inject a bearing fault, watch maintenance ETA, service M-02, then compare Rev A and Rev B at different volumes and redesign investments.
